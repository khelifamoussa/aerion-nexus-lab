# AERION NEXUS Lab

**Autonomous Flight, Intelligent Control & AI Research Laboratory**

A modular four-agent research environment for UAV control, optimization, digital-twin simulation, evidence-based scientific writing, critical review, and publication lifecycle management.

> Engineering Intelligence Beyond Flight

## Preserved production reference

The current evidence laboratory remains available at:
https://aerion-evidence-lab.khalifamoussa21.chatgpt.site/research.html#results

This repository is the maintainable source for the next-generation upgrade. The existing production Site is treated as the baseline and rollback reference; it must not be overwritten until regression and visual acceptance checks pass.

## Four research agents

1. **Problem Architect** — bounded problem formulation, hypotheses, evidence and experiment plans.
2. **Simulation Engineer** — models, controllers, estimators, optimizers and traceable experiments.
3. **Scientific Writer** — equations, figures, tables, manuscripts and journal-compliant exports.
4. **Critical Reviewer** — scientific red-team review, reference integrity and publication strategy.

## Upgrade principles

- Preserve before extending.
- No fabricated references, DOI values, experiments or results.
- Every result must link to model, configuration, seed and experiment ID.
- Clearly label simulated, estimated, measured and literature-reported evidence.
- Build a real immersive 3D research hangar, not a card-based dashboard.
- Keep a complete Scientific 2D mode for performance and accessibility.
- Keep the architecture modular and suitable for future backend services.
